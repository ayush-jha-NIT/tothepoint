# Part 12: SEO & Discovery

## Routes
- `/robots.txt`: generated by `src/app/robots.ts`. Blocks staging/unknown domains, and excludes API, redirects, draft legal pages and unverified testimonials from crawling.
- `/sitemap.xml`: generated from the exactly 17 public routes (5 core + 6 services + 6 blogs). Unverified testimonials are excluded. No misleading lastModified dates.
- `/opengraph-image`: generated 1200×630 PNG social image with brand palette, no externally downloaded font or fake portrait.
- Canonical URLs and absolute metadata are derived from `getSiteOrigin()`; none use localhost.

## Publishing on verified domain
Set `NEXT_PUBLIC_SITE_URL=https://your-real-domain.com` in Vercel (no trailing path/query). Redeploy after changing this environment variable. Verify `/sitemap.xml`, `/robots.txt`, OG image and canonical tags before submitting to Google Search Console or Bing Webmaster Tools.

If a domain isn't configured, the site intentionally serves `Disallow: /`, an empty sitemap and `noindex` meta tags. This prevents accidental indexing of localhost or preview deployments.

A Vercel production `.vercel.app` hostname may be used only if `SEO_ALLOW_VERCEL_DOMAIN=true` is explicitly set and `VERCEL_ENV=production`. Preview deployment aliases are never canonical.

## Structured data
- `Organization` and `WebSite` on the shared layout when a valid origin exists.
- `Service` and `BreadcrumbList` on each service detail route.
- `BlogPosting` and `BreadcrumbList` on each educational guide.
- Breadcrumbs for About, Services, Blog and Contact.

No unverified address, working hours, portrait, formal certification, aggregate ratings, fake client reviews, invented author or publication dates were added. No LocalBusiness with fictional address.

## Content and technical SEO
- All published pages have descriptive metadata.
- Article content is server-rendered MDX with category-based linking and working heading anchors.
- Footer provides internal navigation across page families.
- Semantic HTML headings, live input labels, responsive local SVG graphics and contact information support human visitors without changing content claims.
- Robots noindex stays on the three legal drafts and unverified Testimonials.
- Social image is generated at build/runtime without third-party CDN access.
